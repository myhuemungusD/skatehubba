# Beta Menu Screen Setup Instructions

## ✅ Files Created:

1. **BetaMenuScreen.js** - The main menu screen component
   - Location: `features/beta/BetaMenuScreen.js`
   - Shows "Sesh", "map", "shop" menu options
   - Matches the design from your image

2. **MapScreen.js** - Basic map screen for navigation
   - Location: `features/map/MapScreen.js` 
   - Simple placeholder for now

3. **Updated Navigation** - Added both screens to the navigation

## 🖼️ Background Image Setup:

**IMPORTANT:** You need to save your menu background image:

1. Save your skatehubba menu image as: 
   ```
   assets/images/skatehubba-menu-bg.png
   ```

2. Make sure the image includes:
   - The character with Thrasher hoodie
   - The skateboard
   - All the sponsor logos (Baker, DVS, Independent, etc.)
   - The dark graffiti background

## 🎮 Menu Functions:

- **"Sesh"** → Navigates to Sessions screen
- **"map"** → Navigates to Map screen  
- **"shop"** → Navigates to BetaShop screen

## 🚀 How to Test:

1. Make sure the background image is saved in the correct location
2. Navigate to the "BetaMenu" screen in your app
3. Tap the menu options to test navigation

## 📱 Screen Features:

- **Full-screen background** with your exact image
- **Responsive text sizing** that adapts to different screen sizes
- **Touch-friendly menu buttons** with hover effects
- **Orange/yellow styling** matching your design
- **Bold typography** with text shadows for visibility

The menu screen is now ready to use! Just add the background image and test the navigation.

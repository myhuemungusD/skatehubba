# Lobby Feature

This folder contains the Lobby feature for SkateHubba.

## Overview
- List of active live lobbies (sessions).
- Each lobby shows: host, spot, number of skaters, number of spectators.
- Join to chat live, spectate games, or challenge anyone to a 1v1 game of SKATE.
- Verified pros/shops display special status.
- “Live” indicator for current lobbies.
- Tap a lobby to enter (opens lobby chat and spectate options).

## Planned Components
- LobbyList: View and filter active lobbies
- LobbyChat: Live chat for each lobby
- LobbySpectate: Spectate games in a lobby
- LobbyChallenge: Challenge skaters in a lobby

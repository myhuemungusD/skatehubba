# Challenge Feature

This folder contains the Challenge feature for SkateHubba.

## Overview
- Challenge any skater to a Game of S.K.A.T.E. (live or async).
- See open challenges (sent to you or by you).
- Accept, decline, or spectate a challenge.
- Track letters, tricks, and status for each challenge.
- Async: land a trick, record, submit—wait for the challenger’s response!
- Live: play turn-by-turn in a live lobby.
- Real-time notifications for new moves or challenges.

## Planned Components
- ChallengeList: View and manage open challenges
- ChallengeLobby: Play live or async games
- ChallengeStatus: Track progress, letters, and tricks
- ChallengeNotifications: Real-time updates

Add your challenge-related screens, components, and logic in this folder.

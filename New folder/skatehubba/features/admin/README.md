# Admin Feature

This folder contains the Admin feature for SkateHubba.

## Overview
- Admin dashboard: view/manage users, verification requests, reported content, and shop/spot submissions.
- Approve or deny verification requests (pro/shop/flow).
- Ban/suspend users or shops if needed.
- Manage featured spots, shops, promos, and pro events.
- Review reports (content, profiles, sessions).
- Admins have special badge and access (role-based).

## Planned Components
- AdminScreen: Dashboard for admin actions
- AdminVerification: Manage verification requests
- AdminReports: Review reported content
- AdminUserManagement: Manage users and shops

## Getting Started
Add your admin-related screens, components, and logic in this folder.

# Verification Feature

This folder contains the Verification feature for SkateHubba.

## Overview
- Grant verified status to pros, shops, and sponsored skaters.
- Add verification badge everywhere a verified account is shown (profile, lobby, shop, check-ins, sessions).
- Users can apply for verification or link sponsor/shop for official “flow” or “shop rider” badges.
- Verification requests reviewed by admin/mod team.
- Public verification on spots, brands, and shops (e.g. “This is a real skate shop!”).

## Planned Components
- VerificationBadge: Reusable badge UI for verified status
- VerificationScreen: Request verification or link sponsor/shop
- VerificationAdmin: Review and manage requests (future)

Add your verification-related screens, components, and logic in this folder.

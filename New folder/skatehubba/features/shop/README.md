# Shop Feature

This folder contains the Shop feature for SkateHubba.

## Overview
- Explore real skate shops and brands on the map.
- Verified shops can post deals/promos, host check-ins, and go “live.”
- Users can check in to shops, see shop events, and get discounts.
- Shop profiles show verification badge, deals, staff, and shop sessions.
- Pros/flow riders can link their shop sponsors to their profile.

## Planned Components
- ShopMap: View and explore shops/brands on a map
- ShopProfile: Shop details, deals, staff, sessions
- ShopCheckIn: User check-in and event participation
- ShopLive: Live shop events and promos

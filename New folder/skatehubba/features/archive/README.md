# Archive Feature

This folder contains the Archive feature for SkateHubba.

## Overview
- User “skate resume”: every spot skated, tricks landed, lines, and video clips.
- Upload and manage video clips and photos.
- Each archive entry: spot, date, trick/line name, media, and optional description.
- Show off best clips/tricks at the top of your profile.
- Connects with check-ins and map spots.
- Archive is public by default, but privacy controls possible.

## Planned Components
- ArchiveList: View and manage archive entries
- ArchiveUpload: Add new clips/photos
- ArchivePrivacy: Control archive visibility

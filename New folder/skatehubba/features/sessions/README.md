# Sessions Feature

This folder contains the Sessions feature for SkateHubba.

## Overview
- Join or create a skate session (live or async).
- See a list of active sessions—join to play, spectate, or chat.
- Each session: real-time chat, current players, spectators, status (live, waiting, finished).
- Verified pros/shops show up at the top of the list.
- Tap a session to join/spectate/challenge.
- Spectators can challenge anyone in the lobby to a 1v1 game.

## Planned Components
- SessionList: View and filter active sessions
- SessionLobby: Join, spectate, or challenge players
- SessionChat: Real-time chat for each session
- SessionCreate: Start a new session

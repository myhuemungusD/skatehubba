# Check-ins Feature

This folder contains the Check-ins feature for SkateHubba.

## Overview
- See who’s checked in at any spot or shop (real-time or recent).
- Users can check in at their current location (spot/shop).
- Show live status—see who is currently skating, checked in, or active nearby.
- Checking in can unlock shop deals, session invites, or limited content.
- “Online” status is visible if enabled in settings.
- Special badge for checked-in pros, shop staff, or sponsors.

## Planned Components
- CheckinsList: View spots/shops and checked-in skaters
- CheckinButton: Check in at a location
- CheckinBadges: Show special status for pros, shops, sponsors

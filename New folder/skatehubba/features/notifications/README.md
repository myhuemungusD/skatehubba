# Notifications Feature

This folder contains the Notifications feature for SkateHubba.

## Overview
- Get notified for: new challenges, session invites, shop promos, friend check-ins, pro events, and chat messages.
- Push notifications (Expo/Firebase or device) and in-app alerts.
- Notification center: list all recent notifications, mark as read.
- Tap a notification to jump to the relevant feature (challenge, session, shop, etc).
- Badge on app icon/tab if there are unread notifications.

## Planned Components
- NotificationScreen: Notification center UI
- NotificationService: Push/in-app notification logic
- NotificationBadge: Show unread count on tab/app icon

## Getting Started
Add your notification-related screens, components, and logic in this folder.
